# NEON ROYALE V8

Score-only fictional arcade. No real money, deposits, withdrawals, cash prizes, or exchange.

## Local
npm install
npm start
Open http://localhost:3000

## Admin
http://localhost:3000/admin
Default: admin / admin123
Set ADMIN_USER and ADMIN_PASS on Render to change it.

## Render
Build: npm install
Start: npm start
Root Directory: empty

Data is stored in data/store.json. Render's free filesystem is not permanent across all redeploy/restart situations; for permanent storage use a persistent disk or managed database later.
